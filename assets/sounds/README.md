# Sound assets

Drop four short WAV files here to give the graphical game audio. The game runs
fine without them — a missing file is simply silent.

| File            | Plays when              |
|-----------------|-------------------------|
| `move.wav`      | a move settles          |
| `capture.wav`   | a move captures a piece |
| `jump.wav`      | a piece jumps           |
| `game_over.wav` | the king is captured    |

Free, no-attribution sources: pixabay.com/sound-effects, mixkit.co/free-sound-effects,
kenney.nl/assets/interface-sounds.
